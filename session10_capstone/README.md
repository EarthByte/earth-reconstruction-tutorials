# Session 10 — Capstone

No fixed notebook for this session. Each student picks one **extension** notebook from the
source tutorial suite ([EarthByte/GPlately-pyGMT-tutorials](https://github.com/EarthByte/GPlately-pyGMT-tutorials))
that goes beyond the 33 core notebooks used in Sessions 1–9, and adapts its
`# === USER CONFIGURATION ===` block to a new region, time window, model, or dataset of their
choosing.

Deliverables: the adapted notebook, a short written reflection on what changed and why, and a
five-minute in-class presentation. See `instructor_notes/Instructor_Notes_Overview.md` for
suggested assessment weighting and a reminder to check each student's chosen notebook's data
requirements (some extension notebooks in the source suite need the companion Zenodo archive)
before they commit to one.
